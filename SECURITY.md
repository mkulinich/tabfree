# Security policy

Please report vulnerabilities privately through GitHub's **Report a vulnerability** (Security tab),
not in issues. Include what you found, how to reproduce it and the impact you see. We acknowledge
within 3 working days and aim to fix critical issues within 14 days, crediting you unless you prefer
otherwise.

Supported versions: the latest minor release receives security fixes. The threat model is in
[docs/security/threat-model.md](docs/security/threat-model.md).
